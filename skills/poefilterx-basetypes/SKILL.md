Use the selected game's names verbatim in filter conditions. Quote values containing spaces.
Find bases by name, item class, attributes, or tier. Str, Dex, and Int identify Strength, Dexterity, and Intelligence. T1 identifies the highest tier within an equipment family.
Use each matching entry's `name` in a `BaseType` condition.

`BaseType == "Conquest Lamellar";`
